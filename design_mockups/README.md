## 设计规范

### 1. 产品视觉定位

- 关键词：沉浸、克制、稳定、可长时间阅读。
- 核心体验优先级：内容可读性 > 操作效率 > 装饰感。
- 模块气质区分：
  - 阅读与书架偏安静、留白多、信息层级清楚。
  - 发现与媒体允许更强的颜色识别和氛围图形。
  - 规则与工具页偏专业控制台，强调密度与反馈准确性。

### 2. 设计基准

- 设计基准尺寸：`375 x 812`
- 安全区策略：
  - 顶部按 iPhone 刘海机处理。
  - 底部操作区至少预留 `24px` 安全边距。
- 页面外边距：
  - 常规页左右 `16px`
  - 卡片密集页左右 `20px`
  - 弹层内容区 `20px - 24px`

### 3. 颜色与 Token

以 `design_system.css` 为准，页面禁止自行发明主色。

#### 核心色

- 主色 `--ds-accent`: `#1677ff`
- 主色加强 `--ds-accent-strong`: `#0f62fe`
- 主色浅底 `--ds-accent-soft`: `rgba(22, 119, 255, 0.10)`
- 成功 `--ds-success`: `#22c55e`
- 警告 `--ds-warning`: `#f59e0b`
- 危险 `--ds-danger`: `#e34d59`

#### 中性色

- 主要文字 `--ds-text-primary`: `#1f2329`
- 次级文字 `--ds-text-secondary`: `#4e5969`
- 说明文字 `--ds-text-tertiary`: `#86909c`
- 分割线 `--ds-line`: `rgba(229, 230, 235, 0.92)`
- 主表面 `--ds-surface`: `rgba(255, 255, 255, 0.94)`
- 弱表面 `--ds-surface-soft`: `rgba(255, 255, 255, 0.72)`
- 背景层 `--ds-surface-muted`: `#f7f8fa`
- 染色背景 `--ds-surface-tint`: `#f8fafc`

#### 使用规则

- 文字颜色优先用 token，不直接用纯黑。
- 危险操作只在删除、清空、退出确认等场景使用红色。
- 状态色只承担反馈，不承担主导航识别。
- 模块识别可用渐变，但按钮和主交互仍以主色系统为准。

### 4. 字体与层级

- 全局字体：`SF Pro Display / PingFang SC / Segoe UI / sans-serif`
- 标题建议：
  - 页面标题：`20-24px / 700`
  - 区块标题：`16-18px / 700`
  - 卡片标题：`15-17px / 600-700`
- 正文建议：
  - 主正文：`14-16px / 400-500`
  - 辅助说明：`12-13px / 400`
- 数字与关键状态建议提高字重，优先 `600-800`。
- 阅读页正文与系统页正文分离定义，不要混用系统页字号逻辑。

### 5. 圆角、阴影、间距

- 设备圆角：`--ds-radius-device = 40px`
- 大卡片：`--ds-radius-xl = 30px`
- 常规卡片：`--ds-radius-lg = 22px`
- 中小组件：`--ds-radius-md = 18px`
- 按钮/输入项：`--ds-radius-sm = 14px`

- 页面纵向节奏：
  - 页面级区块间距 `24px - 36px`
  - 卡片内元素间距 `8px - 12px`
  - 表单项垂直间距 `12px - 16px`

- 阴影使用：
  - 浮层与手机外框使用强阴影
  - 卡片使用柔和阴影
  - 列表项默认不加重阴影，优先用分割和背景对比

### 6. 导航与页面结构

#### 一级结构

- 主导航固定为：书架 / 发现 / 媒体 / 我的
- 一级页面优先使用沉浸式头部或大标题头部，不要回退成普通后台列表风格。

#### 二级结构

- 二级管理页统一采用：
  - 顶部导航栏
  - 搜索 / 筛选 / 排序工具条
  - 列表内容区
  - 悬浮操作按钮或底部操作栏

#### 三级与弹层

- 轻量编辑优先底部弹层。
- 高复杂度表单、调试流程、浏览器流程使用独立页面。
- 危险动作必须二次确认，并给出影响范围说明。

### 7. 组件规范

#### 列表项

- 高度优先落在 `56 / 64 / 72 / 88` 四档。
- 左侧图标或封面，右侧主信息区，最右侧状态或操作。
- 一屏内不要出现超过两种列表样式。

#### 卡片

- 书籍卡片强调封面、书名、进度、更新状态。
- 媒体卡片强调封面图、时长、播放状态。
- 工具卡片强调标题、说明、当前配置值。

#### 按钮

- 主按钮：实底主色
- 次按钮：浅底或描边
- 危险按钮：仅删除/清空流程使用
- 图标按钮默认 40x40，圆角与 `icon-btn` 系统一致

#### 表单

- 专业型表单使用分组卡片，避免长白底连续堆叠。
- 输入框下方保留说明区，用于示例、错误提示和规则解释。
- 书源编辑、校验、调试必须有“当前状态 / 最后结果 / 操作反馈”区域。

### 8. 页面状态规范

每个功能页面至少补齐以下状态：

- 默认态
- 加载态
- 空状态
- 错误态
- 选择/批量态

其中：

- 搜索页必须有“未搜索 / 搜索中 / 有结果 / 无结果 / 中断”五态。
- 书源校验必须有“待校验 / 校验中 / 成功 / 失败 / 部分异常”五态。
- 阅读器辅助页至少覆盖“默认 / 激活搜索 / 章节跳转 / 设置展开”。

### 9. 动效与反馈

- 列表进入和切换使用轻量动效，时长建议 `180ms - 240ms`。
- 阅读器、播放器、浏览器等高频页面避免夸张转场。
- 长任务必须显示明确进度或阶段描述，不能只有无限 loading。
- 成功提示优先短 Toast / SnackBar，失败提示需要可行动建议。

### 10. 适配与可访问性

- 最小需要兼容窄屏手机与桌面窗口窄态。
- 触控热区不低于 `44x44px`。
- 正文与背景对比度满足可读性要求。
- 不依赖单一颜色表达状态，需搭配图标或文字。
- 表单校验信息必须直接贴近字段出现。

## 维护规则

- 新增设计稿时，同时更新 `design_mockups/index.html` 与本说明文档。
- 新稿件文件名继续沿用 `序号_功能名.html` 规范。
- 同一功能的弹层如果是关键交互，允许单独编号，不与主页面混写。
- 如果某个页面只复用现有稿件，不新建文件，也要在本说明里登记“复用来源”。
